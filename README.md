# 基金投资记录

一个个人向的基金投资跟踪 Web 应用，把分散在多个直销平台（南方基金、摩根、广发基金等）的持仓聚合到一处，做收益分析和定投管理。

## 关于

最初是为了解决"持仓分散在好几个 App 里、每天切来切去看净值"的痛点而写的。每个平台都只展示自己那部分的收益，想看跨平台的整体表现（按日、按周、按月、最新净值日盈亏、年化 XIRR）就只能手动汇总。

特性：

- **聚合持仓**：跨平台、跨基金类型（指数 / 债券 / QDII / 混合）
- **真实净值**：自动从东方财富拉历史净值，T+1 自动确认份额；美股跟踪 QDII 默认按数据驱动模式剔除节假日占位条目，三档过滤（`auto` / `strict` / `off`）可在「设置」里切换
- **卖出按份额录入**：卖出的份额由你填，成交金额与实际到手自动算（手续费从成交额里扣，不减少份额）；配「全部卖出」一键填入全部份额，编辑历史记录时填的是**该笔交易之前**的持仓。买入侧只在**交易当日的净值**已知时才推算份额——当日净值未发布就按「待确认」记账并在发布后自动补齐，绝不用"最近交易日"的旧净值推算（那会静默算错份额）
- **技术指标**：MA250 偏离度（6 档温度计）、MACD（金叉 / 死叉 / 多空头）、净值回撤百分位——全部基于**分红复权净值**计算（分红除息不再产生虚假信号），回撤百分位用 mid-rank 平局处理（创新高日不再虚标"便宜"）。Dashboard 估值桶与近 5 日金叉 / 死叉计数，FundDetail NAV 曲线叠加 MA250 + 三张指标卡
- **收益分析**：总收益、最新净值日盈亏、年化（XIRR）、累计分红、各基金表现排名
- **定投管理**：周 / 双周 / 月 / 日多种频率的执行追踪
- **周报月报**：自动生成，附各平台、类型的收益贡献和最佳 / 最差基金
- **数据自主**：纯前端，数据存在本地 localStorage，支持导出 / 导入备份；备份提醒条在超过提醒周期（默认 7 天，可在「设置」调整）后自动出现，一键导出；实验性的「自动备份到本地文件」（Chrome/Edge，File System Access API）可在「设置 → 数据管理」开启，应用启动时按自动备份周期（默认 7 天，0 = 关闭）静默写入选定的备份文件。**两个周期相互独立**——关掉提醒条不会顺带关掉自动备份

## 技术栈

- **React 18 + TypeScript 5.6 + Vite 6** —— SPA 基础
- **Ant Design 5**（中文本地化）—— UI 组件
- **ECharts**（echarts-for-react）—— 饼图、折线图
- **Zustand 5** —— 单 store 全局状态管理
- **React Router 6** —— 路由（GitHub Pages 下用 `BrowserRouter + basename="/fund-tracker"`）
- **dayjs** —— 日期处理
- **uuid** —— 交易 / 定投计划 ID

纯前端无后端。东方财富 `pingzhongdata` 接口不支持 CORS，所以用 `<script>` 注入（JSONP 风格）拉数据。净值历史以 `fund-tracker:nav:{基金代码}` 为键存在 localStorage。

## 本地运行

```bash
npm install
npm run dev        # Vite dev server，HMR
npm run build      # Type-check + 生产构建，输出到 dist/
npm run preview    # 预览构建产物
```

## 部署

push 到 `main` 分支触发 `.github/workflows/deploy.yml`：先跑单测（`npm test`，失败即阻断部署），再 build，把 `dist/` 部署到 GitHub Pages。Vite 已配置 `base: '/fund-tracker/'`，与仓库名一致。

数据完全在浏览器本地，不上传到任何服务器。备份三重保障：手动导出 JSON、超期页内提醒、（实验性）本地文件自动备份。

## 已知限制

- 净值数据源为东方财富 `pingzhongdata` 单点：若某只基金切换到带未公开 `sc` 字段的新格式，该基金会被跳过更新（防御性检测，避免写入错误净值），Dashboard / 基金详情页会显示醒目警告；备选方案 `f10/lsjz` 接口实测无 CORS 头（2026-11），浏览器直连不可行，迁移需自建代理（见 `fundApi.ts` 注释）
- 中 / 美节假日字典覆盖 2025-2027，2028 年起需等官方安排公布后补充；未收录年份退化为"仅按周末判定"
- 技术指标的分红复权依赖真实累计净值：2026-11-17 之前拉取的历史里累计净值是近似值（= 单位净值）。这类旧历史会在下次刷新时**自动回填**真实累计净值（只改累计净值、不动单位净值），无需手动重置；只有当上游返回的累计净值本身不完整时，整只基金会退回"不复权"口径（宁可不给信号，也不错信号）
- MA250 偏离度的 ±15% / ±30% 阈值对所有基金统一，对债券等低波动基金基本无分辨力（实测偏离度常年 ±2% 以内），低波动基金的估值请勿依赖该桶
- 浏览器 localStorage 通常只有 5 MB，全量净值历史（15 只基金约 2.2 万条 ≈ 2.8 MB）已占约 56%。写入失败时页面顶部会出现常驻红色警告条，此时最近的改动**只在内存里**，请立刻导出备份并清理不再持有的基金
